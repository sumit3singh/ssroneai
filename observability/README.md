# SSR One AI — Enterprise Observability & Monitoring

This directory contains configuration, log parsers, metrics exporters, tracing spans, and alert rules for production infrastructure.

## Modules

* `logging/` — Structured JSON logging standards and ELK/Loki aggregators.
* `metrics/` — Prometheus metrics instrumentation rules.
* `tracing/` — OpenTelemetry distributed tracing context propagators.
* `monitoring/` — Grafana dashboards and health check probes.
