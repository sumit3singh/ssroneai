# Security Policy

## Reporting a Vulnerability

If you find a security issue, please report it to the maintainers immediately.

- Do not create a public issue for security vulnerabilities.
- Share details privately with the project maintainers.

## Supported Versions

This repository is a monorepo for SSR One AI. The backend uses Python 3.12, and frontend apps use Node.js 20.

## Security Practices

- Keep dependencies up to date.
- Do not commit secrets or credentials into version control.
- Use `.env.example` for environment variable templates.
