## 🏛️ Project & Research Alignment (SSR ONE AI)

Both courses are systematically anchored in the enterprise codebase **`SSR One AI` (`e:/2026/ssr_one_ai`)**, an advanced multi-tenant hospitality SaaS POS and ERP system.

* **Major Project (MSCS-4-03P)**:  
  * **Approved Title**: *"Design and Implementation of a High-Throughput, Offline-First, Multi-Tenant SaaS Enterprise POS Architecture with Integrated AI Copilot and Computer Vision OCR"*
  * **Scope**: Full-stack enterprise architecture encompassing React 19, Dexie.js IndexedDB, FastAPI ASGI, PostgreSQL 16 Row-Level Security (RLS), WebSockets, and Tesseract OCR.
* **Seminar (MSCS-4-04)**:  
  * **Approved Topic**: *"Architectural Patterns for Offline-First Distributed Web Applications: Balancing Zero-Latency User Experience with Eventual Consistency"*
  * **Scope**: Theoretical and practical research on local-first web storage, asynchronous reconciliation queues, idempotency tokens, and distributed conflict resolution.
