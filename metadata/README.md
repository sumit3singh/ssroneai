# SSR One AI — Metadata Engine

This directory contains JSON/YAML metadata definitions driving dynamic UI, permissions, forms, tables, and workflows.

## Metadata Specifications

* `forms/` — Dynamic UI form definitions (fields, validations, layouts).
* `tables/` — Dynamic data grid schemas (columns, filters, actions).
* `reports/` — Custom report queries, metrics, and chart layouts.
* `workflow/` — Visual workflow process schemas.
* `permissions/` — Role & tenant permission matrices.
