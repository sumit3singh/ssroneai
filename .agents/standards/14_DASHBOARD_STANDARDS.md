# Dashboard Standards – BAITHAK ERP Charter #14

## Mandatory Dashboard Components
Every module dashboard MUST contain:
1. **KPI Scorecards**: 4 top summary cards (Revenue, Orders, Active Status, Conversion).
2. **Visual Analytics**: Interactive Recharts graphs (Sales Trends, Category Breakdown).
3. **Recent Activity Feed**: Real-time operational logs.
4. **Quick Action Buttons**: Direct triggers for Master creation and Transactions.
