# Navigation Standards – BAITHAK ERP Charter #09

## 1. Global Navigation Hierarchy
- **Level 1**: Module Launcher (`/`) -> Platform Home grid of cards.
- **Level 2**: Module Workspace -> Active module sidebar navigation.
- **Global Search**: `Ctrl+K` Command Palette for instant navigation across all pages.
- **Breadcrumbs**: Top-left breadcrumbs showing `Module / Section / View`.
