# Component Library Standards – BAITHAK ERP Charter #11

## Reusable UI Primitives (`@/shared/ui/primitives/*`)
- `Button`: Primary, secondary, outline, danger variants with loading states.
- `Input`: Accessible form inputs with label, helper text, and error states.
- `Card`: Container wrapper with header, content, and footer sections.
- `Badge`: Status tags (`success`, `warning`, `danger`, `info`).
- `Dialog`: Accessible modal popup with backdrop blur and trap focus.
- `Table`: Virtualized data tables with sorting, filtering, and pagination.
