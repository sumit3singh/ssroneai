# Design Token Documentation – BAITHAK ERP Charter #23

## Central Token Definitions
- **Colors**: Primary (`emerald-600`), Background (`slate-50` / `slate-950`), Border (`border`), Card (`card`).
- **Border Radius**: Cards (`3xl`), Modals (`3xl`), Buttons (`xl`), Inputs (`xl`).
- **Typography**: Display (`font-black font-display`), Body (`text-xs font-bold`).
- **Shadows**: `shadow-card`, `shadow-modal`.
