# Platform Admin Blueprint – BAITHAK ERP Charter #19

## Platform Administration Governance
Platform Admin (`/platform`) is the super-control workspace for managing:
1. **Tenants**: Onboarding & tenant organization setup.
2. **Companies & Branches**: GSTIN and branch outlet registration.
3. **Licensing**: Node subscription plans, user quotas, and module entitlements.
4. **Audit Logs**: Platform-wide activity audit trails.
