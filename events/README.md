# SSR One AI — Event-Driven Architecture

This directory defines domain events, message schemas, and event bus handlers enabling asynchronous event-driven enterprise processing.

## Event Domains

* `inventory/` — Stock adjusted, transfer requested, reorder threshold reached events.
* `purchase/` — Purchase order created, approved, goods received events.
* `finance/` — Invoice generated, payment settled, reconciliation completed events.
* `sales/` — Order placed, POS ticket closed, refund processed events.
