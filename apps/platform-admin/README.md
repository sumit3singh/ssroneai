# SSR One AI - Platform Superadmin Owner Portal (`apps/platform-admin`)

## Overview
This application is the dedicated **SaaS Platform Superadmin Portal** for SSR One AI platform owners.

> [!CAUTION]
> **Strict Boundary**: This app is strictly isolated for platform administrators. End-customers and hotel/restaurant tenant admins **CANNOT** access this application.

## Key Capabilities
- **Tenant Management**: Onboard new hotel/restaurant company tenants, manage domains, database isolation levels (Shared Schema vs Dedicated DB).
- **Licensing & Tiers**: Issue licensing keys, assign subscription tiers (Starter, Professional, Enterprise), and set outlet/user limits.
- **Billing & Usage Metering**: View API consumption metrics, subscription status, and automated platform billing logs.
- **Global Audit & Security**: System health monitoring, global feature toggles, and platform-wide security audit trails.
