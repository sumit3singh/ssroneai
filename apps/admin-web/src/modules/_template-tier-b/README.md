# Tier B Lightweight Admin Module Template

This directory serves as the canonical Tier B module blueprint for admin/utility modules (Settings, Connected Apps, Roadmap, Project Tracker, Dynamic Forms, AI Copilot).

## Blueprint Layout

- `module.json`: Module manifest.
- `README.md`: Overview.
- `routes.ts`: Route definitions.
- `api/`: REST API clients.
- `components/`: UI components.
- `pages/`: Route screens.
- `types/`: TypeScript definitions.
