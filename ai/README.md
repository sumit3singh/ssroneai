# SSR One AI — Platform AI Engine

This directory provides native AI capabilities powering SSR One AI Copilot and autonomous agents across modules.

## AI Modules

* `copilot/` — Enterprise Copilot assistant implementation.
* `agents/` — Autonomous domain agents (Inventory Agent, Revenue Optimization Agent, POS Assistant).
* `prompts/` — System prompt templates, guardrails, and role instructions.
* `memory/` — Multi-turn conversation and session state management.
* `rag/` — Vector RAG, document parsing, and knowledge base retrievers.
* `tools/` — Function calling schemas and tool declarations for AI agents.
* `embeddings/` — Vector embedding generation pipeline.
