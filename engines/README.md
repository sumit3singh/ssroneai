# SSR One AI — Enterprise Business Engines

This directory contains extracted, reusable core business engines powering the platform.

## Sub-Engines

* `workflow/` — Visual workflow state machine engine.
* `approval/` — Multi-tiered hierarchical document & transaction approval engine.
* `notification/` — Multi-channel notification pipeline (In-app, Push, Email, SMS, WhatsApp).
* `rules/` — Dynamic business rules & decision matrix evaluation engine.
* `audit/` — Zero-trust audit log and compliance engine.
* `scheduler/` — Enterprise cron, recurring task, and background job dispatcher.
* `report/` — Dynamic reporting & PDF generation framework.
* `search/` — Enterprise multi-entity full-text search engine.
